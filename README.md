# Dr. Sehar Ikram — Website

Built with TanStack Start, React and Tailwind CSS. Pre-rendered to static HTML and hosted on GitHub Pages.

## Run locally

```sh
npm install
npm run dev        # http://localhost:8080 (or the port shown in the terminal)
```

## Build & preview the production site

```sh
npm run build      # output goes to .output/public
npm run preview
```

## Deploy

Push to `main`; the GitHub Actions workflow in `.github/workflows/deploy.yml` builds and publishes to GitHub Pages.
